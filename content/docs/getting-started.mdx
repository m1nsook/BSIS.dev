---
title: Getting started
description: How to add and organize documentation pages.
---

## Create a new page

Create `content/docs/your-page.mdx`:

```markdown
---
title: Your page
---

## Hello

Write documentation in Markdown or MDX.
```

Open `/docs/your-page` to view it.

## Organize navigation

Edit `content/docs/_meta.json` to set the order of sidebar links.

## API documentation

Edit `openapi.yaml` to document your actual endpoints. The example `/health` endpoint is a placeholder.
