## Public availability

BSIS core is a **private, experimental Rust repository**, not a published CLI or library yet. There is no public binary release.

The first source prototype is documented in the [Rust prototype guide](./prototype/), including build, install and uninstall commands for maintainers with access to the private repository.

For the longer-term vision, see [architecture](./architecture/), [configuration](./configuration/), and [roadmap](./roadmap/).

## Working on BSIS.dev

The documentation site uses Next.js 16, AriaDocs, Tailwind CSS 4 and Bun.

~~~powershell
bun install --frozen-lockfile
bun run dev
~~~

To check changes before opening a pull request:

~~~powershell
bun run lint
bunx tsc --noEmit
bun run build
~~~

The site automatically deploys from the public BSIS.dev main branch using GitHub Actions. The current address is https://m1nsook.github.io/BSIS.dev/.
