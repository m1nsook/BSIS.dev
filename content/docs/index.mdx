**BSIS (Better NSIS)** is a new open-source project exploring a developer-friendly way to create Windows 10/11 installers.

> **Project status: Early design.** There is no released BSIS engine or stable public API yet. The architecture, configuration samples and plugin interfaces on this site are proposals and may change.

## Core areas

BSIS aims to support installation, uninstallation, bootstrapping, updating and downloading. A single project could offer a fully customized **graphical installer**, an **interactive terminal mode**, and a **silent mode** for deployment automation.

The long-term goal is for developers to design installer screens using familiar UI technologies while delegating privileged filesystem and Windows operations to a dedicated native engine.

## About this documentation

This site is public and may change frequently as the design evolves. The BSIS engine repository remains private while the framework is under development. All example APIs should be treated as illustrative until a release explicitly documents them as supported.
