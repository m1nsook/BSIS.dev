Welcome to **BSIS**. Find setup guides, usage examples, and the API reference in one place.

## Getting started

New to BSIS? Begin with the [getting started guide](/docs/getting-started) to learn how these docs are organized and where your guides belong.

## API reference

Explore the [API reference](/reference) for endpoint definitions, request parameters, and response examples. The current OpenAPI file contains a placeholder endpoint for demonstration.

## Writing documentation

All guides live in `content/docs`. Add an `.mdx` file and update `_meta.json` to choose the sidebar order. You can write regular Markdown, embed links, and include highlighted code examples.
