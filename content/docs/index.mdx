**BSIS (Better NSIS)** is an early-stage open-source project for building customizable Windows installers.

> **Current status: Experimental Rust prototype.** The core source repository remains private. No public installer builder, supported SDK or production release exists yet.

## What exists today

A first Rust proof of concept supports JSON-defined file payloads, a standalone Windows Setup.exe with **Zstandard-compressed files**, a console installer, SHA-256 verification and a cautious receipt-based uninstall. These features remain experimental.

- [Rust prototype](./prototype/) — Windows build and test commands.
- [Configuration](./configuration/) — the actual version 1 JSON schema.
- [Packaging](./packaging/) — the provisional embedded archive format.
- [Roadmap](./roadmap/) — what is implemented and what comes next.

## The long-term vision

BSIS aims to make installer development feel like building a website. Custom graphical interfaces, a TypeScript authoring API, multiple compression algorithms, a plugin ecosystem, a full Windows integration layer, and production-ready updater/repair workflows remain **planned features**.

Public documentation will continue to evolve while the engine stays private through development.
